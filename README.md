# MIAIPlugin

AI-assistent til Microsoft Word, Excel, PowerPoint (og senere Outlook), der kører på **lokale modeller på brugerens egen maskine** (Ollama, LM Studio, llama.cpp m.fl.). Cloud-modeller (fx Claude) kan valgfrit slås til.

> Status: planlægning. Ingen kode endnu.

## Funktioner (målbillede)
- Ret stavning og grammatik som track changes
- Omskriv, parafrasér, forenkl eller skift tone
- Oversæt indhold
- Generér artikler/blogindlæg ud fra én linje
- Forklar og generér Excel-formler i almindeligt sprog
- Generér præsentationsdisposition og omsæt tekst til slides
- Chat med dit dokument, og senere agent-tilstand og lokal RAG
